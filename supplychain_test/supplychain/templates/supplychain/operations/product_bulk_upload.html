Bulk Upload Products

Upload an Excel file (.xlsx) or .csv to create/update products and set current stock levels.

Required columns
  • name
  • unit_cost
  • uom_code
  • stock_level (use 0 if none)
Optional columns
  • sku (Automatically generated if not provided)
  • uom_name
  • description
  • categories (comma-separated)
  • vendors (comma-separated)
  • assigned_users (comma-separated emails)
